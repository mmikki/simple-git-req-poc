# TC-002: Offset validation - invalid bounds

## Test Description
Verify that offset configuration validation rejects values outside the acceptable range (1-90 days).

## Preconditions
- Offset configuration API is available
- Authentication is configured
- Test user has admin privileges

## Test Steps
1. **Test minimum boundary**
   - Send request to set offset to 0 days
   - Verify rejection with 400 Bad Request

2. **Test maximum boundary**
   - Send request to set offset to 91 days
   - Verify rejection with 400 Bad Request

3. **Test valid boundaries**
   - Send request to set offset to 1 day
   - Verify acceptance with 200 OK
   - Send request to set offset to 90 days
   - Verify acceptance with 200 OK

## Expected Results
- Invalid offsets (< 1 or > 90) are rejected
- Valid offsets (1-90) are accepted
- Error responses include validation error message
