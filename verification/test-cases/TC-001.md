# TC-001: Email notification delivery - valid address

## Test Description
Verify that email notifications are sent successfully to valid email addresses.

## Preconditions
- Test user account exists with valid email address
- Email service is configured and operational
- Notification offset is set to 7 days before expiry
- Current date is 7 days before test subscription expiry

## Test Steps
1. **Trigger notification scheduling**
   - Run notification scheduler
   - Verify job queues notification task

2. **Verify email sending**
   - Check email service logs
   - Confirm email was sent to test user address

3. **Validate email content**
   - Retrieve sent email
   - Verify subject line contains "subscription renewal"
   - Verify body includes subscription ID and expiry date

## Expected Results
- Email is successfully sent to test user
- Email contains correct subscription information
- Email delivery status is logged as "sent"
