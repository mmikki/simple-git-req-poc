# TC-005: RBAC authorization enforcement

## Test Description
Verify that role-based access control correctly enforces permissions and denies unauthorized access.

## Preconditions
- Multiple test users with different roles exist
- Test API endpoints are available
- Admin role has full permissions
- User role has limited permissions

## Test Steps
1. **Test authorized access**
   - Login as admin user
   - Access admin-only endpoint
   - Verify 200 OK response

2. **Test unauthorized access**
   - Login as regular user
   - Attempt to access admin-only endpoint
   - Verify 403 Forbidden response

3. **Test permission revocation**
   - Remove admin role from test user
   - Attempt to access admin endpoint
   - Verify access is denied

## Expected Results
- Authorized users can access permitted resources
- Unauthorized users receive 403 Forbidden
- Revoked permissions take effect immediately
- All authorization decisions are logged
