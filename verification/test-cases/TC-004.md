# TC-004: TOTP authentication flow

## Test Description
Verify that TOTP-based multi-factor authentication works correctly for user login.

## Preconditions
- Test user account exists
- MFA is enabled for test user
- TOTP secret is configured
- Authenticator app is set up with QR code

## Test Steps
1. **Initiate login with valid credentials**
   - Enter username and password
   - System requests TOTP code

2. **Enter valid TOTP code**
   - Generate code from authenticator app
   - Enter code in TOTP prompt
   - Submit authentication

3. **Verify successful login**
   - Check that user is authenticated
   - Verify session is established
   - Check authentication logs

## Expected Results
- Login succeeds with valid credentials and TOTP code
- User session is created
- Authentication event is logged
