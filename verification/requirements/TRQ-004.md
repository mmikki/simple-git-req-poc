# TRQ-004: Verify TOTP multi-factor authentication

## Objective
Verify that TOTP-based multi-factor authentication works correctly for user login and account security.

## Test Scope
- TOTP setup and QR code generation
- Valid TOTP code acceptance
- Invalid TOTP code rejection
- Time window tolerance for code validation
- Backup code functionality
- TOTP secret secure storage
- User enable/disable MFA capability

## Success Criteria
- Users can successfully enable MFA
- Valid TOTP codes grant access
- Invalid codes are rejected
- Codes work within acceptable time windows
- Backup codes function as expected
- TOTP secrets are securely stored (encrypted)
- Users can disable MFA when needed
