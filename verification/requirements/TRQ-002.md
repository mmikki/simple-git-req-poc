# TRQ-002: Verify offset configuration and validation

## Objective
Verify that notification offset configurations are properly stored, validated, and enforced within acceptable bounds.

## Test Scope
- Configuration storage and retrieval
- Offset validation (minimum 1 day, maximum 90 days)
- Rejection of invalid offset values
- Configuration updates without system restart
- Different offsets for different notification types

## Success Criteria
- Valid offsets (1-90 days) are accepted and stored
- Invalid offsets are rejected with clear error messages
- Stored configurations persist across system restarts
- Multiple offset types can be configured independently
- Configuration changes take effect immediately
