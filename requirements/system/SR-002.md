# SR-002: Offset validation and bounds enforcement

## Description
The system shall validate notification offset values to ensure they are within acceptable ranges.

## Requirements
- Minimum offset: 1 day before expiry
- Maximum offset: 90 days before expiry
- Reject invalid offset configurations
- Log validation failures

## Dependencies
- SR-001: Configurable pre-expiry notification offsets (validation requires the offset configuration mechanism to exist first)
