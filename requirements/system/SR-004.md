# SR-004: Multi-factor authentication support

## Description
The system shall support optional multi-factor authentication (MFA) using time-based one-time passwords (TOTP) or SMS codes.

## Requirements
- Support TOTP-based MFA (e.g., Google Authenticator, Authy)
- Support SMS-based MFA as fallback
- Allow users to enable/disable MFA for their accounts
- Provide backup codes for account recovery

## Dependencies
None
