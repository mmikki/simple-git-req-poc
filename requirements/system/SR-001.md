# SR-001: Configurable pre-expiry notification offsets

## Description
The system shall allow configuration of notification timing offsets relative to subscription expiry dates.

## Requirements
- Support configurable offset values in days (e.g., 7 days before expiry)
- Store notification offset configurations persistently
- Allow different offsets for different notification types
- Support offset adjustment without system restart

## Dependencies
None
